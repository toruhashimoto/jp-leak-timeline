# 漏洩カミングアウトタイムライン

Claude Fable 5 のリリース（2026年6月10日）以降に公表された、日本の企業・組織の情報漏洩・不正アクセス事案を時系列でまとめた静的サイトです。

公開ページ: https://toruhashimoto.github.io/jp-leak-timeline/

## 構成

- `index.html` — 表示（検索・種別フィルタ・並び替え・月別グラフ）
- `data.js` — 事案データ。追加・修正はここだけ

## データの追加

`data.js` の `INCIDENTS` に1行追加します。

```js
I("2026-10-10", "組織名", "概要", "件数の表示文字列", 123456, "access", ["出典URL", "出典名"]),
```

`type` は `access`（不正アクセス）、`ransom`（ランサムウェア）、`config`（設定・認証不備）、`human`（人為ミス・内部）、`vendor`（委託先・連鎖）のいずれかです。

## 注意

- Fable 5 のリリース日は期間の区切りとして使っているだけです。掲載事案と AI の悪用との因果関係を示すものではありません。
- 公表日・件数はまとめ記事や報道をもとにした初報ベースの値です。正確な情報は各組織の一次発表を確認してください。
- 網羅的なリストではありません。
