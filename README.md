# 漏洩カミングアウトタイムライン

Claude Fable 5 のリリース（2026年6月10日）以降に公表された、日本の企業・組織の情報漏洩・不正アクセス事案を時系列でまとめた静的サイトです。

公開ページ: https://toruhashimoto.github.io/jp-leak-timeline/

## 構成

- `index.html` — 表示（検索・種別フィルタ・並び替え・月別グラフ・発生→検知→公表の時間軸）
- `data.js` — 事案の一覧（組織名・概要・件数・報道まとめの日付など）と AI モデルの登場
- `timelines.js` — 公式発表から拾った各事案の日付イベント（発生・検知・公表・続報）と原因タグ
- `lib.js` — 日数計算・集計の関数（`derive` / `summarize` / `countBy`）。統計ページを作るときもこれを使う

## データの追加

1. `data.js` の `INCIDENTS` に1行追加します。

```js
I("2026-10-10", "組織名", "概要", "件数の表示文字列", 123456, "access", ["出典URL", "出典名"]),
```

`type` は `access`（不正アクセス）、`ransom`（ランサムウェア）、`config`（設定・認証不備）、`human`（人為ミス・内部）、`vendor`（委託先・連鎖）のいずれかです。

2. 公式発表に日付があれば、`timelines.js` に同じ組織名をキーにして追加します。

```js
"組織名": {
  officialUrl: "公式発表のURL",
  events: [
    E("incident", "2026-10-01", "公式発表の原文（短く）", "@"),
    E("anomaly", "2026-10-03", "…", "@"),
    E("disclosed", "2026-10-10", "…", "@")
  ],
  causes: ["vuln"], causeText: "原因に関する原文"
}
```

イベント種別、原因タグ、曖昧な日付の扱い（`date: null` にして `raw` に原文を残す）は `data.js` 冒頭のコメントにまとめています。日数は表示側で計算するので、手で入力しません。

## 注意

- Fable 5 のリリース日は期間の区切りとして使っているだけです。掲載事案と AI の悪用との因果関係を示すものではありません。
- 発生・検知・公表の日付は各組織の公式発表に明記されたものだけを使っています。件数はまとめ記事や報道をもとにした初報ベースの値です。
- 網羅的なリストではありません。
